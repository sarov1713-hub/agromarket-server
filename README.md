# АгроМаркет API

## Запуск

npm install
npm run dev

Сервер: http://localhost:3000

## Эндпоинты

| Метод | Путь | Описание | Ответы |
|---|---|---|---|
| GET | /api/health | проверка сервера | 200 |
| GET | /api/products | товары, ?search= | 200 |
| GET | /api/products/:id | один товар | 200, 404 |
| GET | /api/orders | список заявок | 200 |
| POST | /api/orders | новая заявка | 201, 400 |

## Лабораторная 5 — ответы

- Content-Type у `res.send()` и `res.json()` отличается. `res.send()` может возвращать обычный текст, а `res.json()` возвращает JSON с соответствующим типом содержимого.
- Если в middleware не вызвать `next()`, запрос не передаётся дальше по цепочке и клиент не получает ответ от следующих обработчиков.
- Если поставить логгер после маршрутов, уже обработанные маршруты до него не дойдут, поэтому такие запросы логироваться не будут.
- Без `express.json()` Express не разбирает JSON-тело запроса, поэтому `req.body` остаётся пустым или неопределённым, и сервер возвращает ошибку валидации.
- ИИ использовался для объяснения структуры Express-проекта, проверки кода, настройки маршрутов, middleware, CORS и отправки формы из React.
